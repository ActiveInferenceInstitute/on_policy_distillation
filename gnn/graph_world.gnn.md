## ModelName

Deterministic Graph-World Topology Validation

## ModelAnnotation

A deterministic four-node graph world (start -> cue -> choice -> goal) with an
`advance` / `stay_goal` action pair. The model is dynamic: each topology's
declared trace is walked to its terminal node and the reachability witness is
bound to a Lean theorem (see `../src/roadmap_tracks/formal_interop.py` and
`../lean/OnPolicyDistillation/`). The topology trace itself is generated by
`../scripts/simulate_si_graph_world.py`; this specification is the canonical
structural description, not a second copy of the numbers.

## InitialParameterization

# Deterministic world: `src/simulation/graph_world.py:_graph_world_trace` fixes
# the walk, so there are no fitted priors, likelihoods or transition
# probabilities to declare. The initial state is node index 0 (`start`) of the
# declared state block at step 0, where the goal test is false; the walk then
# advances start -> cue -> choice -> goal with goal_probability step / 3. The
# terminal `goal_reached` witness is emitted to
# output/data/si_graph_world_summary.json, not declared as an initial value.
goal={(0.0)}
