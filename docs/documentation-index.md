and agent instructions. Generated runtime artifacts under `output/` and manuscript
source fragments are outside this documentation inventory. The `docs` gate's
`test_flat_documentation_index_is_complete` checks this list against the tree;
add or remove the corresponding entry whenever a documentation page changes paths.
